# 翻译 JSONL 查看器

一个用来**校对机翻结果**的桌面小工具：逐条展示「英文原文 / 中文翻译」，边看边查，改完的文件可以直接丢给 VSCode 编辑。

## 这个软件解决什么问题

renpy-live-translator 之类的实时翻译工具会把游戏文本的翻译结果导出成 `.jsonl` 文件，每条记录一行 JSON：

```json
{"source": "Save the game?", "translation": "保存游戏？"}
```

直接用文本编辑器打开这种文件，原文和译文挤在同一行，中文还会被转义成 `\uXXXX`，校对时非常难读。本工具把它渲染成**一行原文 + 一行译文**的对照视图，并提供搜索、跳转、字号调节等阅读辅助功能。

## 功能

| 功能 | 说明 |
| --- | --- |
| 文件夹 / 文件选择 | 输入或浏览任意文件夹，自动列出其中所有 `.jsonl` 文件，下拉切换；默认打开项目内置的专属译文目录 |
| 原文译文对照 | 每条记录占 3 行（原文本身含换行符时相应增多）：`[序号]` + 英文原文（深蓝）、中文翻译（深绿）、空行 |
| 关键字过滤 | 实时过滤（200 ms 防抖），不区分大小写，**原文和译文都参与匹配** |
| 下一文件 | 一键切到列表中的下一个文件（末尾循环回第一个） |
| 行号跳转 | 输入记录序号回车或点「跳转」，定位到该条并按实际行数浅黄高亮 1.5 秒 |
| 正文字号 | `Ctrl + 鼠标滚轮`，只改正文字体，UI 不变（8–32） |
| 界面字号 | `Ctrl + =` 放大、`Ctrl + -` 缩小，只改 UI 字体，正文不变（8–24） |
| 会话记忆 | 关闭时记住文件夹 / 文件 / 搜索词 / 滚动位置，下次启动自动恢复 |
| VSCode 打开 | 一键用 VSCode 打开当前 jsonl 文件，改完存盘在查看器里切一下即可看到新内容 |
| 横向滚动 | 原文过长不折行，用底部横向滚动条查看 |

## 运行环境

- Windows + Python 3（需要 **tkinter**，python.org 官方安装包自带）
- 无需安装任何第三方库
- 已在本机 Python 3.15 + Tk 9.0 上验证

## 使用方法

双击 `启动查看器.bat`（无控制台窗口），或命令行运行：

```bash
python translation_viewer.py
```

`启动查看器.bat` 的查找顺序：`%LOCALAPPDATA%\Programs\Python\Python315\pythonw.exe` → PATH 中的 `pythonw` → PATH 中的 `python`。若 Python 装在别处，直接改 bat 里的 `PY315` 变量即可。

启动后：

1. 启动时会自动打开内置的专属译文目录 `translations\camp-buddy-scoutmaster`（该目录不存在时需手动选择）；换游戏或译文换位置时点「浏览...」选择存放 `.jsonl` 的文件夹；
2. 顶部的文件下拉框里选择要校对的文件；
3. 在搜索框输入关键字快速定位，或输入行号跳转；
4. 需要修改时点「VSCode打开」，改完保存，回到查看器切换文件即可刷新。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `translation_viewer.py` | 主程序，单文件实现（tkinter GUI） |
| `启动查看器.bat` | 免控制台启动脚本 |
| `viewer_state.json` | 会话记忆文件，运行时自动生成，**不入库**（见 `.gitignore`） |

## 数据格式说明

- 每行一条 JSON 对象：`{"source": 英文原文, "translation": 中文翻译}`
- 文件按 **UTF-8** 读取，自动兼容带 BOM 的文件
- 空行、非法 JSON 行、以及不是 JSON 对象的行（数组 / 纯字符串等）会被跳过，跳过条数显示在底部状态栏
- `source` / `translation` 缺失或为 `null` 时按空字符串处理，非字符串类型会自动转成字符串
- 序号 `[NNNN]` 是**有效记录在文件中的顺序号**（跳过的空行与无效行不占号），与过滤状态无关，方便对照原文件；文件无空行、无无效行时与物理行号一致

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + 鼠标滚轮 | 放大 / 缩小正文字号 |
| `Ctrl` + `=` | 放大界面字号 |
| `Ctrl` + `-` | 缩小界面字号 |
| 搜索框回车 / 点「跳转」 | 按行号定位 |

## 已知限制

- 大文件（2 万条以上）过滤时每次输入都会全量重绘，单次约 0.3 秒；暂未做分页或只渲染前 N 条。
- 过滤状态下重绘会把视图滚回顶部，不保留原滚动位置。
- 文件必须为 UTF-8（可带 BOM）。用编辑器保存成 GBK 等编码时不会显示乱码，而是在内容区提示「不是 UTF-8 编码」，另存为 UTF-8 后切换文件即可恢复。
